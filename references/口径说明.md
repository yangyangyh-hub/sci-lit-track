# 口径说明（通用版）

> 本文件定义"什么算合格的一次文献追踪"。**改口径必须改本文件并升版本号**。
> 具体领域的方向、词表、期刊门槛写在 `config/directions.json`，不在本文件里。

---

## 1. 目的

周期性（建议每周）把近 2–4 周正式发表的论文，按用户关注的若干方向筛选、排序，整理成结构化中文进展报告，
供组会选文、精读排队（可衔接单篇解读类技能）。

## 2. 方向与范围

- **方向由用户配置**：`config.directions[]`，每个方向一个 `name` + 一组检索词。
- **组内 OR、组间 AND**：`query` 是给数据源的宽检索式，`core` 是判相关性用的核心词。
- **主题漂移控制**（可选，逐方向）：
  - `require_any`：必须命中其中一个强词，否则排除；
  - `exclude_terms`：命中即排除（如只做动物研究时排除 plant/virus/tumor）；
  - `zone_cat_allow` + `zone_cat_strict`：限定期刊大类（需要分区表）。
- **禁止为凑数纳入无关论文**。不足就少收（见 §6）。

## 3. 数据源

| 源 | 角色 | 关键点 |
|---|---|---|
| PubMed E-utilities | 主干（生医） | 时间字段用 `[EDAT]`（入库日）；部分网络环境需代理，脚本按域名自动路由 |
| Europe PMC | 补充 | 用 `FIRST_IDATE`；要排除预印本必须加 `SRC:MED` |
| OpenAlex | 补充（跨学科） | 必须带 `mailto`；`created_date` 过滤不可靠，降级用 `publication_date` 并标注 |
| Crossref | 补充（补小众刊） | 日期过滤用 `from-created-date`（`from-pub-date` 对部分出版商无效） |

**代理**：不写死端口。脚本按域名路由，代理不可用时回退直连并报错。
**去重**：DOI 归一（小写、剥 `https://doi.org/`）为主键；无 DOI 退 PMID；再退标题归一哈希。
同一 DOI 多源命中**记录全部来源**；日期取值优先级 PubMed 入库日 > Crossref created > OpenAlex publication_date。

## 4. 时间窗

- **优先近 14 天**；
- 某方向不足目标篇数时，**放宽相关性并延长到 28 天**补位；
- **期刊门槛不随时间放宽**；
- 超出 28 天的记录直接不用。

## 5. 筛选（三级漏斗，逐级计数）

**5.0 出版方硬排除（最高优先级，读摘要前执行）**
按 `exclude_publishers` 配置：`publishers`（精确匹配出版机构）、`journals`、`journal_prefixes`、`known_titles`。
出版机构从分区表的 `出版机构` 字段按 ISSN 反查；缺失 ISSN 时按刊名规则。
**默认配置不含任何黑名单**，由用户自行决定；若配置了某出版方，**不访问其官网**。

**5.1 硬排除**
预印本 / 社论·评论·勘误·撤稿 / 非目标生物（按方向配置）/ 相关性不足（标题无命中且 `rel<2`，此类仅保留给 28 天补位）。

> **摘要长度不作门槛**：部分期刊本身就要求短摘要（如 <400 字符），按长度筛会误删优质文献。
> 若确有需要，用配置项 `min_abstract_chars`（默认 0 = 不限）。

**5.2 期刊门槛（三种模式，任选其一）**

| mode | 判定 | 适用 |
|---|---|---|
| `zone_if`（默认） | 分区 ∈ `zone_allow`（默认 1 区/2 区）**或** IF > `if_min`（默认 4） | 有分区表与 IF 表 |
| `journal_list` | 期刊名命中 `journals` 列表（支持 `Xxx*` 前缀） | 无分区表，或领域有公认核心刊清单 |
| `none` | 不设期刊门槛 | 探索期，慎用 |

**不允许静默丢弃**：任一排除原因都要出现在运行的漏斗统计里。

## 6. 排序与配额

```
相关性 rel 降序（标题命中×3 + 摘要命中）
→ 内容倾向（prefer 命中多记 +1，clinical 命中多记 −1）
→ 分区档位（1区且IF>8 → 1区 → IF>4）
→ 用户指定优先项（如某物种优先）
→ 首次在线日期（新→旧）
```

- 每方向目标 **10 篇**（可配）；14 天＋补位到 28 天仍不足，**如实少收**。
- **单归属**：同一 DOI 只归一个方向，取相关性最高的方向。

## 7. 输出

### 7.1 报告结构

```
# <日期> 文献进展
## 一、精选导读        ← 相关性最高、影响因子最高的若干篇（默认 5）：题名｜期刊｜分区｜IF｜链接
## 二 ~ N、各方向       ← 每篇：中文译题（作标题）
                        正文首条=英文原题全文 → 期刊/分区/IF/首次在线 → 直达链接 → DOI → 摘要整段中译
```

- **不写**：漏斗统计、排除原因、口径说明、核验过程 —— 读者只要结果。
- **每篇必须有直达链接**：`https://doi.org/<DOI>` → PubMed → PMC → Europe PMC；
  都取不到时写「暂无直达链接」，不许给搜索页。

### 7.2 内容规则

- 标题用**中文译题**；正文首条是**英文原题全文**（不截断、不改写）。
- 正文主体 = **原文摘要的整段中文译文**（`abstract_cn`）：按摘要原序逐句译，
  **不再拆「背景 / 方法 / 主要结果 / 结论」四段**；不重排、不压缩成要点、不加评论。
- 摘要确实缺失的写「原刊未提供摘要」，**禁止推测**；数字、样本量、基因名、限定语照原文。
- 术语首次出现用「中文（英文）」；不写"具有重要意义"式空话。

### 7.3 投递

报告目录由 `SCI_RADAR_OUTDIR` 环境变量或 `--outdir` 指定，默认写入**项目内 `reports/`**
（若用户指定了固定目录则以用户为准，且**只保留一份，不留副本**）。

## 8. DOI 核验（强制）

多源合并会出现 **DOI 与题名不是同一条记录**。做法：对最终收录的每篇用 Crossref 反查题名做 Jaccard 比对：

- 相似度 ≥ 0.5 → `ok`
- < 0.5 → 按题名反查，≥ 0.75 者取为真 DOI（`fixed`，报告标注"已修正"）
- 反查不到或只能匹配到预印本 → **留空并标"DOI 待核"**，不猜测

**未经核验的 DOI 不得写进报告。**

## 9. 工程约定

- 唯一流水线 `scripts/funnel.py`；核验 `scripts/verify_doi.py`；成稿 `scripts/build_report.py`。
- 依赖仅 `openpyxl`（读 xlsx）；解释器用带该包的 venv。
- 脚本与中间数据**不要放在 `.cache/`**（会被清理）。
- 邮箱等个人信息通过环境变量或配置传入，脚本内不含任何账号信息。

## 10. 已知限制

| 限制 | 现状 | 处理 |
|---|---|---|
| 无分区表/IF 表 | 无法用 `zone_if` 门槛 | 改用 `journal_list` 或 `none`，并在报告中说明 |
| 单源单方向结果上限 | PubMed 300 / EPMC 200 / OpenAlex 100 / Crossref 100 | 顶格时存在召回损失，需缩小检索式或分页 |
| OpenAlex 入库日不可得 | `created_date` 过滤 429/超时 | 降级出版日并标注 |
| 物种/对象判定 | 仅靠摘要文本，易漏判 | 判不出按配置推断并打标，供人工复核 |
| 摘要中译质量 | 依赖模型翻译，无自动校验 | 交稿前按《内容撰写指南》自检；缺译篇目由 `build_report.py` 在控制台点名 |
| 短摘要文献 | 摘要过短时译文偏短 | 不做长度过滤；原刊摘要多短就译多短，不补不扩 |
